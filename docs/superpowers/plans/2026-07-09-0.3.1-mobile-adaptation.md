# aptbot 0.3.1 WebUI 移动端适配实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 将 0.3.0 完成的 React WebUI 从桌面专用布局扩展为响应式,覆盖手机(<768px)/平板/桌面(≥768px)三档视口。核心特性为侧边栏抽屉化与 InputArea 快捷指令自动缩放,其余组件做间距/字号/全屏化适配。UAT 全绿后必须用户人工验收通过才能封仓。

**Architecture:** 采用方案 C 混合方案 — 静态布局(间距/宽度/显隐)交给 Tailwind `md:` 响应式类(零 JS),动态交互(抽屉开闭/遮罩/快捷指令溢出测量/模态全屏切换)交给 JS state + 自写轻量 `useIsDesktop` hook。768px 为断点阈值。不引入新依赖(除自写 hook),不重构后端,不清理 0.3.0 之前的遗留代码。

**Tech Stack:** React 19, Vite 6, Tailwind CSS v4 (`md:` 响应式类), lucide-react (`Menu`/`X` 图标), TypeScript, vitest(单元测试), Playwright(UAT)。无新依赖。

## Global Constraints

- 断点阈值:768px(Tailwind `md`),<768px 移动抽屉模式,≥768px 桌面固定侧边栏
- 状态分层:静态布局用 Tailwind `md:` 类(零 JS),动态交互用 JS state + `useIsDesktop` hook
- 不引入新依赖(除自写 `use-media-query.ts` + `use-quick-actions-layout.ts` hook)
- 不重构后端 / API / WebSocket 协议

## Task 2: 基建 hook — use-quick-actions-layout

**Files:**
- Create: `src/webui-react/lib/use-quick-actions-layout.ts`
- Test: `tests/webui-react/use-quick-actions-layout.test.ts`

**Interfaces:**
- Produces: `useQuickActionsLayout(containerWidth: number, buttons: QuickActionButton[]): { visibleButtons: QuickActionButton[]; overflowButtons: QuickActionButton[]; isMeasuring: boolean }`
- `QuickActionButton` 类型:`{ id: string; label: string; icon?: string }`
- 算法:预估每个按钮宽度 = `label.length × 7 + 18 + 16 + 8`(字符×charWidth + iconWidth + padding + gap),容器宽度减去「更多」按钮预留 64px,贪心填充

- [ ] **Step 1: 写失败测试**

测试用例(在 `tests/webui-react/use-quick-actions-layout.test.ts`):
1. 全部放下:containerWidth=2000 + 16 个短 label 按钮,overflowButtons 为空,visibleButtons.length === 16
2. 部分溢出:containerWidth=400 + 16 个按钮,visibleButtons.length < 16 且 overflowButtons.length > 0,且 visibleButtons.length + overflowButtons.length === 16
3. 全部溢出(极窄屏):containerWidth=100,visibleButtons 为空,overflowButtons.length === 16
4. 单个按钮超宽:containerWidth=200 + 1 个超长 label 按钮,该按钮进入 overflow(预估宽度 > 可用宽度)
5. 「更多」按钮预留:overflowButtons 非空时,visibleButtons 总宽度 ≤ containerWidth - 64
6. 边界:containerWidth=0,visibleButtons 为空,overflowButtons.length === 全部

算法函数可独立于 hook 测试(导出纯函数 `computeQuickActionsLayout(containerWidth, buttons)` 便于测试)。

- [ ] **Step 2: 运行测试看 RED**

运行:`npx vitest run tests/webui-react/use-quick-actions-layout.test.ts`
预期:FAIL,`Cannot find module './use-quick-actions-layout'`

- [ ] **Step 3: 写最小实现**

在 `src/webui-react/lib/use-quick-actions-layout.ts`:
- 导出 `QuickActionButton` 类型
- 导出纯函数 `computeQuickActionsLayout(containerWidth, buttons)`:
  - 预估宽度函数 `estimateButtonWidth(btn) = (btn.label?.length ?? 0) * 7 + 18 + 16 + 8`
  - MORE_BUTTON_WIDTH = 64
  - availableWidth = containerWidth - (buttons 是否会溢出 ? MORE_BUTTON_WIDTH : 0) — 注:需先尝试不放「更多」按钮,若全放下则不预留
  - 实现:先尝试全放下(累加 ≤ containerWidth),成功则 overflowButtons=[];失败则用 availableWidth = containerWidth - MORE_BUTTON_WIDTH 贪心填充
- 导出 `useQuickActionsLayout(containerWidth, buttons)` hook:内部调用 computeQuickActionsLayout 返回结果 + isMeasuring(containerWidth === 0 时 true)

- [ ] **Step 4: 运行测试看 GREEN**

运行:`npx vitest run tests/webui-react/use-quick-actions-layout.test.ts`
预期:PASS,6 个用例全绿

- [ ] **Step 5: Commit**

运行:`git add src/webui-react/lib/use-quick-actions-layout.ts tests/webui-react/use-quick-actions-layout.test.ts && git commit -m "feat(0.3.1): Task 2 — useQuickActionsLayout hook + greedy fill algorithm"`
