## 1. 总体架构与断点策略

### 1.1 范围与目标

将 0.3.0 完成的 React WebUI 从桌面专用布局扩展为响应式，覆盖手机/平板/桌面三档视口。主要工作量集中在侧边栏抽屉化与 InputArea 快捷指令自动缩放两个核心特性，其余组件做间距/字号/全屏化适配。

**非目标：**
- 不清理 0.3.0 之前的遗留代码（src/webui/ 旧 Lit WebUI、aistudio-design/、chat-page.ts 旧移动端 CSS）
- 不重构后端 / API / WebSocket 协议
- 不引入新依赖（除自写轻量 hook）

### 1.2 断点与状态分层

**断点：** 768px（Tailwind `md`）。<768px 移动抽屉模式，≥768px 桌面固定侧边栏。

**状态分层原则（方案 C 混合方案）：**
- **静态布局**（间距 / 宽度 / 显隐 / padding / 字号）→ Tailwind `md:` 响应式类，零 JS
- **动态交互**（抽屉开闭 / 遮罩 / 快捷指令溢出测量 / 模态全屏切换）→ JS state + `useIsDesktop` hook

理由：快捷指令「自动缩放适配 + 溢出折叠」必须 JS 测量容器宽度，纯 CSS 无法精确控制；而布局/间距这类静态切换交给 CSS 更简洁可靠。混合方案兼顾两者，且本项目是 Vite SPA 无 SSR，useMediaQuery 无 hydration 闪烁风险。

### 1.3 新增 hook

**`src/webui-react/lib/use-media-query.ts`**（~15 行）：
- 导出 `useIsDesktop()`：返回 boolean，内部用 `matchMedia('(min-width: 768px)')` + resize 监听
- SSR 安全：`typeof window === 'undefined'` 时返回 false（防 happy-dom 测试环境差异）
- useEffect 内 addEventListener + cleanup removeEventListener

**`src/webui-react/lib/use-quick-actions-layout.ts`**：
- 详见 §2.2 快捷指令自动缩放

### 1.4 App.tsx 协调

**新增 state：**
- `sidebarOpen: boolean`（移动端抽屉开闭，默认 false）
- `isDesktop: boolean`（来自 `useIsDesktop()`，在 App 顶层调用一次通过 props 下传避免多处监听）

**新增 props 下传：**
- Sidebar 接收 `isDesktop` + `isOpen` + `onClose`
- 新增 Backdrop 组件接收 `isOpen` + `onClose`（仅移动端 + isOpen 时渲染）

**Body 滚动锁：** 抽屉打开时锁 body 滚动（`document.body.style.overflow = 'hidden'`），关闭时恢复。useEffect 管理，卸载时清理复原。

**main 区 margin：** [App.tsx#L602](file:///Users/evan/projects/aptbot/src/webui-react/App.tsx#L602) 现有 `ml-64` 改为 `md:ml-64`（移动端 ml-0 占满宽度）。

## 2. 侧边栏抽屉化（核心特性）

### 2.1 Sidebar.tsx 改造

**桌面端（≥768px，`md:` 类）：** 保持现状 — `fixed left-0 top-0 w-64 h-full z-20`

**移动端（<768px）：**
- `fixed left-0 top-0 w-64 h-full z-40 transform transition-transform duration-300`
- 关闭：`-translate-x-full`
- 打开：`translate-x-0`
- `max-w-[85vw]`（防超窄屏溢出，沿用 0.2.1 经验）
- box-shadow `shadow-2xl` 增加浮动感

**Sidebar 接收 props：**
- `isDesktop: boolean`
- `isOpen: boolean`（移动端抽屉开闭）
- `onClose: () => void`

**根元素 className 逻辑（描述性，具体实现由 TDD 驱动）：**
```
基础类: fixed left-0 top-0 h-full bg-white border-r border-slate-200 transform transition-transform duration-300
宽度: w-64 max-w-[85vw]
z-index: z-40
位移: isOpen ? translate-x-0 : -translate-x-full  （移动端）
       固定显示无位移                        （桌面端，md:translate-x-0）
阴影: 移动端 shadow-2xl，桌面端无
```

### 2.2 Backdrop 遮罩组件

新增组件（内联在 App.tsx 或独立 `src/webui-react/components/Backdrop.tsx`，由 TDD 决定）：
- 移动端 + isOpen 时渲染：`fixed inset-0 bg-black/30 z-30 md:hidden`
- 点击触发 `onClose`
- `backdrop-filter: blur(2px)` 轻度模糊背景
- transition 配合抽屉动画

### 2.3 Hamburger 按钮与移动端顶栏

App.tsx 在 main 内新增移动端顶栏：
- `md:hidden`（仅移动端渲染）
- 含 hamburger 图标（lucide `Menu`）+ 当前 agent 名称（activeAgent.name，无 agent 时显示 "Aptbot"）
- 不显示会话名（避免与会话切换状态同步的复杂度）
- 点击 hamburger → `setSidebarOpen(true)`

顶栏样式：`h-12 px-3 flex items-center gap-2 border-b border-slate-100 md:hidden`

### 2.4 自动关闭行为（移动端）

以下操作在移动端（`!isDesktop`）触发 `setSidebarOpen(false)`，桌面端不受影响：
- `handleSelectSession`（选择会话）
- `handleSelectAgent`（选择智能体）
- `handleCreateSession`（点击新会话按钮）
- `handleStartNewSessionWithAgent`（NewSessionPicker 选择智能体后）

实现：在各 handler 内追加 `if (!isDesktop) setSidebarOpen(false);`

### 2.5 Esc 键关闭（可访问性）

抽屉打开时按 Esc 关闭。App.tsx 加 useEffect 监听 keydown，`event.key === 'Escape' && sidebarOpen` 时调用 `setSidebarOpen(false)`。

### 2.6 SessionItem 移动端常显按钮

[Sidebar.tsx](file:///Users/evan/projects/aptbot/src/webui-react/components/Sidebar.tsx) 内 SessionItem 现有 hover 显示的删除/重命名按钮在移动端改为常显（移动设备无 hover）：
- `opacity-100 md:opacity-0 md:group-hover:opacity-100`

### 3.3 快捷指令自动缩放（核心特性）

**新增 hook：** `src/webui-react/lib/use-quick-actions-layout.ts`

**输入：**
- `containerWidth`（ResizeObserver 测量）
- `buttons`（16 个 quick actions，每个含 label + 预估宽度）

**输出：**
```
{
  visibleButtons: Button[]      // 可放下的按钮
  overflowButtons: Button[]     // 溢出到「更多」面板的按钮
  isMeasuring: boolean          // 首次测量完成前为 true（避免闪烁）
}
```

**算法：**
1. useLayoutEffect + ResizeObserver 监听容器宽度
2. 预估每个按钮宽度：`label 文本字符数 × charWidth(~7px) + iconWidth(18px) + padding(16px) + gap(8px)`
3. 容器宽度减去「更多」按钮预留宽度（~64px）得到可用宽度
4. 贪心填充：从左到右累加按钮宽度，超过可用宽度停止
5. 剩余按钮进入 overflowButtons，通过「更多 ⋯」按钮弹出面板展示

**边界情况：**
- 全部放下：`overflowButtons` 为空，不渲染「更多」按钮
- 全部溢出（极窄屏 <360px）：`visibleButtons` 为空，仅显示「更多 ⋯」按钮
- 首次渲染未测量：`isMeasuring=true`，渲染占位避免闪烁

**渲染：**
- 桌面宽屏：可能全部 16 个放下（无「更多」按钮）
- 移动端：放下 3-5 个 + 「更多 ⋯」按钮
- 极窄屏（<360px）：仅显示「更多 ⋯」按钮

**弹出面板：**
- 点击「更多 ⋯」展开 grid 面板：`grid grid-cols-3 md:grid-cols-4`
- 含全部 overflowButtons
- 点击面板内按钮 = 触发对应 quick action + 关闭面板
- 点击外部关闭（useRef + mousedown outside 检测）

**显示守护：** 沿用现有 `activeAgentSlug === 'default'` 守护，非 default agent 不渲染快捷指令区。

### 5.4 人工验收门禁（强制）

1. 启动 dev server（`npx tsx --env-file=.env src/server.ts`）+ webui 构建（`npm run webui:build`）

**封仓收尾禁止在人工验收未通过时执行。**
